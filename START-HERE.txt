SOMIIL GUPTA WEBSITE — START HERE

1. Install VS Code and Node.js if you do not already have them.
2. Open Somiil-Website.code-workspace in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm run dev
5. Open http://localhost:8080

EDIT SOURCE FILES ONLY INSIDE src/
Do not manually edit dist/. It is generated automatically.
